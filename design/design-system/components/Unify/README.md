# Unify

**適用済み**（SAA 837542c、2026-10-31）。下の表のとおり `design/tokens.json` を置き換え、寄せた 105 個のトークンをなくした。テーマで食い違っていた所も案のとおりに揃え、テーマファイルにはトークンの値だけが残った。以下は案として出したときの記録。

色の統一の案。旧パレット（`saa-classic-*`）などの 109 個のトークンを、面・縁・文字・アクセントの基本トークンに寄せる。カードの画像は本物のアプリで撮ったもので、Now が今、Unified がこの案を当てたもの（トークンの値を変えただけで、ほかは何も変えていない）。ダークとライトに 9 画面ずつある。原寸での比較は別ページ https://claude.ai/artifact/2G2LoD8Nmt3oCEru2Tr3M5 にある（変わった場所を枠で囲み、画面を押すか Space で Now と Unified を切り替える）。カードの中のプレビューにはクリックが届かないため。

## 見た目で変わるところ
- ライト
  - タグのポップオーバーとタグ選択の Apply、オンの状態（Fixed、選んだプリセット）が、黄土色から選択の色（`saa-bg-selected`、薄い青）になる。
  - フォーカスの線がコーラル色からアクセントの青になる。
  - ギャラリーと設定のスライダー、もとのアプリのボタンのコーラルや金がアクセントになる。
- ダーク
  - もとから近い色なので、変化は小さい。モーダルの文字が #eee から `saa-text`（#e8e8ea）になる程度。
  - スライダーの青から紫へのグラデーションが、アクセント 1 色になる。
  - 右クリックメニューの区切り線（白）が縁の色になる。半透明だったメニューの面が、ほかの浮き面と同じ `saa-bg-panel` になる。
- 両方
  - 作者プロフィールの面と縁が、ほかのポップオーバーと同じになる。
  - もとのプロンプト欄の色付きの文字（橙、黄緑など）が本文の色になる。どの行かは左の帯の色で分かる。
  - タグチップの面・縁・文字が、ほかの操作部品と同じ `saa-bg-control`・`saa-border-ctl`・`saa-text` になる。オフ、除外、お気に入りなどの状態の色はそのまま。

## 足すトークン
- `saa-accent-soft`：アクセントを薄くした地。重みの区画、バッジ、ドロップ先に使う。今は 3 つの違う値で書かれている。
- `saa-backdrop`：モーダルの後ろの暗幕。今は 4 つの違う値で書かれている。

## LoRA のライトの値
今はダーク用の 1 色しかなく、ライトでは読めない（印は 2.4:1）。ライト用に `saa-lora-text` #5b21b6、`saa-lora-mark` #7c3aed、`saa-lora-bg` #efe7ff、`saa-lora-from` #a78bfa を足す。

## テーマで食い違っている所の決め方（案）
- お気に入りの星：ライトだけホバーで金色が消える → 両方とも金のまま（ダークに合わせる）。
- チェックボックスの並び：ライトだけ右に 20px の余白がある → 外す。
- 無効にしたチップのトグルの印：ダークだけ色を指定している → 両方とも `saa-chip-toggle-check`。
- 関連タグのホバーと作者ボタンの文字：ダークだけ白を指定している → 両方とも `saa-text`。
- 作者プロフィールのバーの地：ライトだけ色がある → 両方とも `saa-bar-track`。
- タグ選択から Parts への導線：ライトだけ色がある → 両方とも `saa-part-*`。

## このカードの外で決めるもの
- スロット行の色付きの箱のボタン（緑の＋、赤の−、橙の i）：アイコンボタンにした（SAA 4a38a9f）。
- myDialog.js の青いボタン：Dialog 部品にまとめるときに直す。
- `index.css` の Parts の金（#e0c080 の直書き）：`saa-part-gold` などにした（SAA 837542c）。

## 決め方
この表でよければ、`design/tokens.json` の値を置き換えて `saa-classic-*` を消し、使っている所を基本トークンの名前に書き換える。寄せ先が違うと思う行は、その行を指してコメントで知らせる。
