入口と 2 つのタブ
「+ Add tag」「Choose tags」「Insert part…」「行末の parts ボタン」はすべてこの 1 つのモーダル。前 3 つは Tags タブで、parts ボタンは Parts タブで開く。今の別ウィンドウ「Insert part」ピッカーは Parts タブに吸収して無くす。タブ名は Tags / Parts の文字だけ(アイコン・件数なし)。タブは Ctrl+Tab / Ctrl+1・2 で切替、検索語は 2 つのタブで共通(Tags で打った skirt がそのまま Parts でも効く)。部品が使えない欄(Views / Characters / Action 行、Lists のエントリ編集)はタブ帯を出さず今のまま。
Selected と Apply は共通
Selected はタブをまたいで 1 つ。タグは今の灰チップ、部品は金枠の parts: チップ。Parts タブのタイルはクリックで選択切替(複数可、Hair + Background のような組み合わせ向け)。Apply は選んだ順にカーソル位置へ挿入し、部品は parts: チップ 1 個になる。Apply のラベルは件数付き。
Tags タブからの導線
ツールバーは Parts タブでも同じ 4 枠。Search はそのまま(名前とタグに一致)、Category の選択肢が Outfit / Hair / Body / Background / Other に、Attribute の枠は Sample(All / 今のモデルで生成済 / 未生成)に変わり、★ は部品にお気に入りが無いので淡色で据え置き。Tags タブで検索語に一致する部品があれば一覧の下に「parts: 一致 N 件 → Parts タブ」を出す。右パネルは Main ボードのものを縮めた版: 画像・タグ(無効は取り消し線)・History・Edit part…。フッター左に New part…(エディタ)と Generate missing。
